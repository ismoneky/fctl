# 预约底栏金额占位优化

## 背景

预约页底栏在费用预览尚未成功时展示“请完善信息”。该文案位于主操作按钮左侧，视觉上较零散，也会分散“立即预约”按钮的注意力。

## 设计

- 当费用预览状态为 `incomplete` 时，不渲染左侧金额或提示内容。
- “立即预约”按钮保持现有位置、样式和点击行为，继续作为底栏唯一的主要视觉焦点。
- 当费用预览成功时，底栏只展示后端返回的金额；免费状态只展示“会员免费”“免费预约”或“年龄免费”主结果。
- 底栏费用区不展示出行人数、收费人数、免费人数或解释性副文案。
- 当费用正在计算时，保留轻量的“价格计算中…”反馈。
- 当费用预览失败时，保留现有错误提示，避免隐藏真实故障。
- 表单校验、协议校验、费用预览和提交支付逻辑均保持不变。

## 验收标准

1. 初始进入页面且表单未完整时，底栏左侧不显示“请完善信息”或默认金额。
2. 未完成信息时点击“立即预约”，仍触发现有协议及表单校验提示。
3. 费用预览成功后，只出现金额或免费状态主结果，不出现人数与费用摘要。
4. 费用计算中及计算失败时，仍能看到对应状态反馈。
5. 不引入本地金额兜底，不改变后端费用预览作为唯一金额来源的规则。
